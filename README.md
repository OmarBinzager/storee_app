# Storee (ستوري) 🌸📱

> **الشعار المعتمد:** «كل طلب، وكل ريال، في مكانه»  
> **الهوية البصرية:** Soft Boutique (أنثوي، هادئ، بسيط، منظم)  
> **المنصات واللغة:** Flutter (Android & iOS) — اللغة العربية مع اتجاه RTL أساسي.

---

## 📖 نظرة عامة (Overview)

تطبيق **ستوري (Storee)** صُمم خصيصاً لمندوبات البيع عبر واتساب والتاجرات المستقلات في اليمن ودول الخليج. يعالج التطبيق تشتت تفاصيل الطلبات داخل المحادثات اليومية، ويوفر نظاماً متكاملاً لإدارة طلبيات العميلات، الشراء الجماعي من المتاجر العالمية، الخزنات والحسابات المالية متعددة العملات، التقارير الصافية، والنسخ الاحتياطي المشفر دون الحاجة لاتصال دائم بالإنترنت (Offline-First).

## 💎 القواعد المالية الصارمة (Strict Financial Invariants)

1. **حظر الفواصل العائمة (`double`):** جميع المعاملات المالية تُخزن وتُحسب كأعداد صحيحة `int amountMinor` تمثل أصغر وحدة نقدية (هللات للريال السعودي، سنتات للدولار، والوحدة الصحيحة للريال اليمني) عبر كائن القيمة الموحد `Money`.
2. **العملات المدعومة وعزل الحسابات:** يدعم التطبيق الريال اليمني (`YER` - 0 منازل عشرية)، الريال السعودي (`SAR` - منزلتان عشريتان)، والدولار الأمريكي (`USD` - منزلتان عشريتان). يُحظر جمع أي عملتين مختلفتين دون تحويل صريح.
3. **قبض العميلة ليس ربحاً:** قبض المبلغ هو حركة نقدية في الخزنة وزيادة في السيولة، بينما صافي الربح هو:
   $$\text{صافي الربح} = \text{سعر البيع} - \text{تكلفة الشراء المخصصة} - \text{المصاريف التشغيلية}$$
4. **التحويل الداخلي ليس دخلاً أو مصروفاً:** التحويل بين خزنتين يسجل كحركة خروج ودخول برقم مرجعي موحد، ولا يغير إجمالي أصول المتجر.
5. **فصل السحب الشخصي للمالكة:** تُفصل مسحوبات المالكة الشخصية (`personalWithdrawal`) تماماً عن المصاريف التشغيلية للمتجر حتى لا يتشوه حساب الربح الفعلي.
6. **توزيع تكلفة الشراء الجماعي:** تُوزع تكاليف الشحن والرسوم الإضافية على منتجات العميلات المختلفة بنسبة وتناسب دقيقة بناءً على سعر الأساس لكل عنصر مع معالجة فروق التقريب في أصغر وحدة نقدية (`BatchCostAllocator`).

## 🚀 الميزات المكتملة بالتطبيق

### 1. لوحة التحكم السريعة (Home Dashboard)
- استعراض فوري للمهام العاجلة: الطلبيات الجاهزة للتسليم والطلبات قيد المتابعة.
- بطاقات المؤشرات المالية الذكية مجمعة حسب كل عملة (المبيعات، الأرباح، والمستحقات).
- ملخص الخزنات النشطة وقائمة أحدث الطلبيات مع إمكانية فتح تفاصيل الطلب بنقرة واحدة.

### 2. إدارة العميلات (Customers Management)
- إضافة عميلات وتحديد العملة الافتراضية مع التحقق من صحة أرقام الهواتف (اليمن `+967` والخليج `+966`).
- بطاقة ملف العميلة الشاملة (`CustomerDetailSheet`): إجمالي المشتريات، المبالغ المدفوعة، والمتبقي (الديون).
- سجل طلبات العميلة الكامل وإمكانية إنشاء طلب جديد لها مباشرة.
- أزرار اتصال سريع وتراسل مباشر عبر واتساب بنقرة واحدة.

### 3. الطلبيات ومشاركة الفواتير (Orders & WhatsApp Sharing)
- إنشاء طلبية متعددة المنتجات مع تحديد المقاس، اللون، والكمية، واحتساب إجمالي السعر تلقائياً.
- فلاتر سريعة للطلبات: حسب حالة التنفيذ (جديد، مؤكد، تم الشراء، قيد الشحن، وصل، جاهز للتسليم، تم التسليم) وحالة السداد (غير مدفوع، جزئي/عربون، مدفوع بالكامل).
- ورقة تفاصيل الطلبية (`OrderDetailSheet`): عرض عناصر الطلب، الربح المحقق لكل صنف، وتحديث فوري لحالة التنفيذ.
- توليد نص فاتورة بوتيك أنيقة لمشاركتها مع العميلة عبر واتساب بلمسة زر واحدة.
- زر تسجيل دفعة سريع ومسبق التعبئة لبيانات الطلبية.

### 4. الشراء الجماعي وتوزيع التكاليف (Group Purchasing)
- تجميع طلبات عميلات متعددة في فاتورة شراء واحدة من المورد أو المتجر الخارجي (Shein, Zara...).
- محرك التوزيع النسبي الذكي (`BatchCostAllocator`): توزيع تكاليف الشحن والرسوم بعدالة بناءً على السعر الأساسي لكل قطعة، مع حفظ تكلفة كل عنصر في قاعدة البيانات.
- خيار السداد التلقائي للفاتورة من خزنة محددة وخصم الرصيد بضمان اتساق القيود.

### 5. الخزنات والحسابات المالية (Multi-Currency Wallets)
- إدارة الكاش، الحسابات البنكية (الكريمي، إلخ)، والمحافظ الإلكترونية (جيب، ون كاش).
- عزل أرصدة العملات المختلفة داخل الخزنة الواحدة.
- تسجيل الدفعات وتخصيصها على الطلبيات.
- تسجيل المصاريف التشغيلية وتصنيفها، مع فصل مسحوبات المالكة الشخصية تماماً.
- التحويل الداخلي بين الخزنات مع تثبيت رقم الحركة المرجعي.

### 6. التقارير المالية الذكية (Financial Reports)
- تقرير دوري مفصل لكل عملة على حدة: إجمالي المبيعات، تكلفة البضاعة المباعة (COGS)، تكاليف الشحن الموزعة، المصاريف التشغيلية، وصافي الربح الحقيقي.
- بيان مستحقات العميلات وديون السوق.

### 7. النسخ الاحتياطي المشفر والاستعادة (Offline Encrypted Backup)
- تصدير كامل لقاعدة بيانات SQLite بتنسيق JSON مشفر مع البصمة الرقمية SHA-256.
- اكتشاف محاولات التلاعب بالبيانات أو الملفات التالفة قبل استعادتها.
- استعادة ذرية (Atomic Transaction) في مساحة آمنة لتفادي ضياع البيانات.

### 8. نظام الترخيص الرقمي غير المتصل (Offline Licensing)
- تفعيل التطبيق بمفاتيح رقمية موقعة تشفيرياً (`STOREE-<TIER>-<YYYYMM>-<SIG>`).
- فترة تجريبية مجانية لمدة 14 يوماً عند التثبيت الأول.
- حساب فترات السماح (Grace Period) والتحقق التلقائي دون الحاجة لخادم سحابي دائم.

## ⚙️ متطلبات التشغيل والتطوير (Getting Started)

1. **Flutter SDK:** الإصدار `^3.10.0` أو أحدث.
2. **استنساخ المستودع:**
   ```bash
   git clone git@github.com:OmarBinzager/storee_app.git
   cd storee_app
   ```
3. **تثبيت الحزم وتوليد كود Drift:**
   ```bash
   flutter pub get
   dart run build_runner build --force-jit
   ```
4. **تشغيل التطبيق:**
   ```bash
   flutter run
   ```
